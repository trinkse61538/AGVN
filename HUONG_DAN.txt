AGVN FRONTEND FIX - HƯỚNG DẪN

Gói này không yêu cầu bạn tự sửa từng file HTML.
Workflow sẽ tự động sửa các file hiện có trong repository và tạo lại các trang tự generate.

CÁC VẤN ĐỀ ĐƯỢC SỬA
1. Nội dung desktop bị ẩn khi AOS tải chậm hoặc lỗi.
2. Banner trang chủ gọi các file AVIF/WebP không tồn tại rồi mới fallback sang JPG.
3. Ảnh sản phẩm phải đợi JavaScript chuyển data-src thành src nên xuất hiện chậm.
4. Ảnh bài tin tức chi tiết trong news_template được đặt lại đúng {{ImageURL}}.
5. URL raw.githubusercontent.com được chuyển sang jsDelivr khi có thể.

CÁCH CÀI
1. Giải nén ZIP.
2. Upload nguyên hai thư mục .github và scripts vào thư mục gốc repository AGVN.
3. Commit vào nhánh main.
4. Vào tab Actions.
5. Chọn workflow "Apply AGVN frontend image and AOS fixes".
6. Chọn Run workflow > Run workflow.
7. Chờ workflow hoàn tất màu xanh.
8. Mở website bằng Ctrl + F5 hoặc cửa sổ ẩn danh.

LƯU Ý FILE ẨN
- ZIP có thư mục .github bắt đầu bằng dấu chấm.
- Trên Windows, bật View > Show > Hidden items nếu không nhìn thấy thư mục này.
- Phải giữ đúng đường dẫn: .github/workflows/apply-agvn-frontend-fix.yml

SAU KHI CHẠY THÀNH CÔNG
Bạn có thể giữ hai file patch để dùng lại hoặc xóa:
- scripts/apply-agvn-frontend-fix.js
- .github/workflows/apply-agvn-frontend-fix.yml

Workflow có thể chạy lại an toàn; patch được thiết kế để không chèn trùng CSS.
